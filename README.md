# Leave Desk

Leave Desk — приложение на Rails и PostgreSQL для управления заявками сотрудников на отпуск и процессом их согласования.

## Требования

- Ruby 4.0.2;
- Rails 8.1;
- PostgreSQL 16 или новее.

PostgreSQL должен быть запущен и доступен текущему пользователю. Параметры
локальных баз находятся в `config/database.yml`.

## Первоначальная настройка

```sh
bundle install
bin/rails db:prepare
```

`bundle install` устанавливает зависимости, а `db:prepare` создаёт или обновляет
development- и test-базы. Эти команды не требуется повторять перед каждым
запуском приложения.

## Демонстрационные данные

Seeds создают виды отсутствия, администратора, руководителя, сотрудников,
отпуска и дни рождения для годового календаря. Перед запуском задайте локальный
пароль демонстрационных пользователей:

```sh
DEV_SEED_PASSWORD='выберите-локальный-пароль' bin/rails db:seed
```

Команда идемпотентна: её можно запускать повторно без создания дубликатов.
Список созданных email можно получить без вывода паролей:

```sh
bin/rails runner 'puts User.order(:email_address).pluck(:email_address)'
```

Не используйте демонстрационные учётные данные в production.

## Обычный запуск

```sh
bin/dev
```

Приложение будет доступно по адресу <http://localhost:3000>. Остановить сервер
можно сочетанием `Ctrl+C`.

После изменения ветки или получения новых миграций выполните:

```sh
bundle install
bin/rails db:prepare
```

## Проверка

Тесты приложения:

```sh
bin/rails test
```

Полный набор проверок, используемый в CI — тесты, стиль и анализ безопасности:

```sh
bin/ci
```

## Границы продукта

MVP охватывает создание заявок на отпуск и их согласование руководителем.
Учёт переработок, интеграция с расчётом заработной платы, сложные правила начисления отпусков, единый вход и мультитенантность отложены до появления явных требований.
