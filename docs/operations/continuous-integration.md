# Непрерывная интеграция

GitHub Actions запускает проектные проверки для каждого pull request и каждого
изменения основной ветки. Workflow использует версию Ruby из `.ruby-version` и
PostgreSQL 16.

Для локального запуска всех проверок используйте:

```sh
bin/ci
```

Команда подготавливает базу, проверяет стиль Ruby, уязвимости зависимостей и
безопасность приложения. Затем она запускает обычные тесты, загружает справочные
виды отпуска в тестовую базу и повторяет тесты в одном процессе вместе с
браузерным тестом. Один процесс нужен, чтобы тесты использовали именно
предварительно засеянную базу, а не отдельные базы параллельных рабочих процессов.
Сбой любого шага завершает проверку с ошибкой.

GitHub Actions выполняет проверки в отдельных jobs и повторяет тот же сценарий
для обычных и засеянных тестов. Браузерный тест запускается после загрузки
справочников. Seeds дополнительно проверяются транзакционными тестами в
`test/scripts/seeds_test.rb`; они не меняют итоговое состояние базы.

После успешного CI основной ветки запускается workflow `Deploy`. Он собирает
Docker-образ именно проверенного SHA, публикует теги SHA и `latest` в GHCR и
разворачивает SHA-тег в environment `production`. Ручной запуск `Deploy`
доступен через `workflow_dispatch`.
