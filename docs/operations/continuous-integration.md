# Непрерывная интеграция

GitHub Actions запускает проектные проверки для каждого pull request и каждого
изменения основной ветки. Workflow использует версию Ruby из `.ruby-version` и
PostgreSQL 16.

Единственная точка входа для локального и удалённого запуска:

```sh
bin/ci
```

Команда подготавливает тестовую базу и последовательно проверяет стиль Ruby,
уязвимости Ruby-зависимостей, безопасность приложения и тесты. Seeds
проверяются транзакционным тестом `test/scripts/seeds_test.rb`, поэтому проверка
не оставляет данные в тестовой базе. Сбой любого шага завершает workflow с
ошибкой.
