# Корректировка демонстрационных отпусков 2026 года

Ручной workflow **Correct demo calendar 2026** выполняет согласованную
пользователем коррекцию тестовых данных стенда. Обычный Deploy её не запускает.
В логах выводятся только агрегаты, SHA-256 плана и метаданные резервной копии.
Операция ограничена исходными 20 демо-учётными записями `employee1`–`employee20`
домена `leave-desk.test`; основная учётная запись и новые сотрудники сохраняются.

1. Запустить workflow с `operation=vacations`, `mode=plan`, без `plan_digest`.
2. Проверить количество сотрудников, распределение месяцев и пересечений,
   сохранить полученный `plan_digest`.
3. Запустить workflow с той же операцией, `mode=apply` и этим `plan_digest`. До изменения
   будет создана и проверена отдельная копия в
   `/var/backups/leave-desk/demo-2026-before-correction-XXXXXXXX/`.
4. Проверить итог операции, шаги аудита истории и публичного HTTPS.

Для локальной копии доступны те же режимы:

```sh
DEMO_CALENDAR_MODE=plan bin/rails runner script/correct_demo_calendar_2026.rb
DEMO_CALENDAR_MODE=apply DEMO_CALENDAR_PLAN_DIGEST='<SHA-256 из плана>' bin/rails runner script/correct_demo_calendar_2026.rb
```

История исходных заявок сохраняется через отмену и создание согласованных
замен; исторические дробные ежегодные отпуска остаются без изменений.
Даты рождения и данные 2027 года не меняются. Повторный запуск
возвращает `already_applied`, включая случаи последующей отмены замен
пользователем, и не создаёт повторных событий.

Скрипт резервного копирования передаётся через стандартный ввод SSH.
Команды Docker, которым не нужен входной поток, используют `/dev/null`;
иначе Docker может прочитать оставшуюся часть скрипта. Workflow требует
явное сообщение о проверенном архиве: одного успешного SSH-кода недостаточно.

Для исправления диагонального распределения дней рождения выбрать
`operation=birthdays`, сначала `plan`, затем `apply` с полученным SHA-256.
Изменятся только месяц и день рождения исходных 20 демо-сотрудников;
год и существующие заявки сохраняются. Это отдельная операция, повторный
запуск коррекции отпусков её не выполняет.
