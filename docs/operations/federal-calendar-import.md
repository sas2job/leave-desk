# Импорт федерального календаря

За достоверность праздничных дат, переносов и реквизитов НПА отвечает
администратор. До ввода календаря заявки получают пометку «Календарь года ещё
не подтверждён» и создают встроенные уведомления активным администраторам.
После импорта календарь личного и командного представления сразу учитывает
переносы. Длительность прежних заявок меняется только после явной проверки
администратором на странице «Проверка календаря»; результат записывается в
историю заявки.

## Формат

В [шаблоне](../../data/federal-calendar.template.json) указаны поля JSON:
- `year` — целый год от 2000 до 2100;
- `legal_basis` — полная ссылка на НПА с датой и номером;
- `public_holidays` — массив праздничных дат в формате `ГГГГ-ММ-ДД`;
- `transfers` — массив объектов `{"from":"ГГГГ-ММ-ДД","to":"ГГГГ-ММ-ДД"}`.

Готовые федеральные календари: [2025](../../data/federal-calendar-2025.json),
[2026](../../data/federal-calendar-2026.json),
[2027](../../data/federal-calendar-2027.json). Они содержат переносы по
постановлениям Правительства и автоматические переносы по статье 112 ТК РФ.

Шаблон намеренно содержит пустое нормативное основание и пустой список
переносов. Перед импортом заполните основание, сверьте праздники и внесите
все переносы для выбранного года, включая автоматические переносы праздничных
выходных. Перенесённый выходной не добавляют в
`public_holidays`: он входит в длительность ежегодного отпуска.

## Способы загрузки

Администратор может выбрать JSON на своём компьютере в разделе
«Федеральные календари». Если файл подготовил сотрудник, он передаёт файл
администратору; у сотрудника нет права менять календарь. Загрузка уже
существующего года требует отметки «Заменить уже внесённый календарь».

Оператор приложения может выполнить скрипт с произвольным читаемым путём
на машине запуска, в том числе к файлу внутри проекта:

```sh
bin/import-federal-calendar /path/to/calendar.json
bin/import-federal-calendar --replace data/federal-calendar-2026.json
```

Импорт отклоняет некорректную структуру, даты другого года, повторения и
файл больше 64 КиБ. Неудачная проверка не изменяет календарь. После импорта
администратор сверяет показанные значения, затем проверяет помеченные
заявки. Сохранённая длительность не меняется от одной лишь загрузки файла.
