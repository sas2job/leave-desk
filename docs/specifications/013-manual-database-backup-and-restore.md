# Спецификация 013: ручное копирование и восстановление БД

## Критерии приёмки

1. `bin/backup` создаёт архив и SHA-256 sidecar в указанном абсолютном каталоге
   вне исходного кода; существующие копии сохраняются.
2. `bin/restore` принимает только существующий архив, явно заданный адрес
   изолированной БД и `ALLOW_DATABASE_RESTORE=yes`.
3. Sidecar содержит ровно одну запись SHA-256 с именем выбранного архива.
   Повреждённый архив, некорректный sidecar или sidecar для другого имени
   отклоняются до запуска `pg_restore`.
4. Одновременные ручные запуски `bin/backup`, в том числе в одну секунду,
   публикуют разные пары архив/sidecar. Существующая копия не перезаписывается.
   Отказ одного запуска удаляет только его временные файлы и не повреждает
   результат другого.
5. `bin/backup` создаёт новый каталог с режимом `0700`. Существующий каталог
   принимается только если им владеет запускающий пользователь и его режим
   ровно `0700`. Неподходящий каталог отклоняется до создания архива; скрипт
   не меняет режим и содержимое существующего каталога.
6. Оба ручных скрипта требуют Bash 4+ и документированные внешние команды.
   Отсутствие команды или необходимой возможности Bash приводит к понятной
   ошибке до создания каталога копий, дампа или запуска восстановления.
