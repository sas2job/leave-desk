# Спецификация 014: неиспользуемые маршруты Active Storage

## Критерии приёмки

1. Приложение не публикует маршруты Active Storage для прямой загрузки,
   дискового сервиса, blob и representation. Запрос к прямой загрузке
   возвращает HTTP 404 как без сессии, так и после входа.
2. Форма входа, загрузка JSON-файла федерального календаря через обычную
   multipart-форму и выдача ассетов продолжают работать.
