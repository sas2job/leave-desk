# Спецификация 022: документ о пересечениях

- Только `manager` открывает HTML-отчёт и скачивает Markdown, включая прямые URL.
  Сотруднику и администратору возвращается 403. В выборке только активные
  непосредственные подчинённые текущего руководителя.
- Источник отчёта совпадает с календарём: одобренные заявки и фактические
  использованные части после отзыва или выхода; один сотрудник считается один раз за день.
- Разрез — выбранный год/месяц. Внутри года выводятся только месяцы, где есть
  дни с двумя или более отсутствующими. Сумма дней равна счётчику календаря.
- Соседние даты с одинаковыми участниками объединяются; документ содержит
  период, число и имена участников, время формирования и пояснение дневного критерия.
- Каждый период HTML-отчёта открывает месячную шкалу Gantt с его участниками.
  Идентификаторы сотрудников из запроса не принимаются: состав определяется
  заново на сервере по разрешённой команде и совпадению дат.
- Дневное совпадение не объявляется точным одновременным отсутствием по часам.
  Кадровые основания и семейный вид отсутствия в документ не включаются.
- В календаре администратор сохраняет просмотр отсутствий; отдельные показатели,
  подсветка дневных пересечений и ссылка на отчёт предназначены менеджеру.
