# Спецификация 005: управление сотрудниками

## Критерии приёмки

1. Только пользователь с ролью `administrator` может просматривать и изменять
   справочник сотрудников.
2. Администратор может создать сотрудника с именем, уникальным адресом
   электронной почты, паролем и ролью.
3. Адрес электронной почты нормализуется перед сохранением.
4. Администратор может изменить имя, адрес электронной почты, роль,
   непосредственного руководителя и активность сотрудника.
5. При редактировании пустое поле пароля сохраняет действующий пароль.
6. Непосредственным руководителем может быть только активный пользователь с
   ролью `manager`; сотрудника нельзя назначить руководителем самому себе.
7. Пользователя с непосредственными подчинёнными нельзя лишить роли
   руководителя или деактивировать, пока подчинённые не переназначены.
8. Деактивация не удаляет заявки, решения и другие исторические данные.
9. Удаление сотрудников через интерфейс не поддерживается.
10. Пользователь без роли администратора получает `403 Forbidden`.
11. После успешной деактивации сотрудника или замены его пароля все его
    прежние сессии отзываются. Изменение других полей их не отзывает.
