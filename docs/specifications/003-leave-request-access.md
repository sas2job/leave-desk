# Спецификация 003: доступ к заявкам

## Критерии приёмки

1. Авторизованный пользователь видит только собственные заявки.
2. При создании заявки сотрудник определяется по текущей сессии и не принимается
   из параметров запроса.
3. Пользователь может отменить только собственную ожидающую или одобренную заявку.
4. Руководитель видит заявки только непосредственных подчинённых.
5. Только пользователь с ролью `manager` может открыть очередь согласования.
6. Руководитель может одобрить или отклонить только ожидающую заявку своего
   непосредственного подчинённого. Подчинённость проверяется повторно в
   транзакции решения по заблокированной строке сотрудника.
7. Запрос к чужой заявке, включая перевод сотрудника после первоначального
   поиска заявки, не изменяет её, события и уведомления и возвращает
   `404 Not Found`.
8. Доступ к очереди согласования без роли руководителя возвращает
   `403 Forbidden`.

## Отложено

- делегирование полномочий руководителя;
- многоуровневое согласование;
- доступ администратора к рассмотрению заявок;
- согласование заявок руководителя вышестоящим руководителем.
