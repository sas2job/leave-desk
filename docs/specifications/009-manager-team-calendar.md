# Спецификация 009: годовой календарь команды

## Критерии приёмки

1. Календарь доступен только пользователю с ролью `manager`.
2. Руководитель видит только активных непосредственных подчинённых.
3. Календарь показывает все дни выбранного года, выходные, одобренные заявки и
   дни рождения сотрудников.
4. Ожидающие, отклонённые и отменённые заявки в календарь не попадают.
5. Можно перейти к предыдущему и следующему году.
6. Таблица прокручивается по горизонтали и сохраняет подписи сотрудников.
