# Спецификация 007: аудит заявки

## Критерии приёмки

1. Создание, одобрение, отклонение и отмена создают отдельное событие.
2. Событие содержит исполнителя, время, исходный и новый статус и комментарий.
3. Событие сохраняется в одной транзакции с изменением заявки.
4. Событие нельзя изменить или удалить через приложение.
5. Сотрудник видит историю собственной заявки, руководитель — историю заявки
   непосредственного подчинённого.
6. Комментарий события ограничен 2000 символами Unicode, как комментарии
   заявки и решения.
