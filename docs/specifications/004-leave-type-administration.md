# Спецификация 004: управление видами отпусков

## Критерии приёмки

1. Только пользователь с ролью `administrator` может просматривать и изменять
   справочник видов отпусков.
2. Администратор может создать вид отпуска с уникальным кодом и названием.
3. Код нормализуется в верхний регистр.
4. Администратор может изменить название и доступность вида отпуска.
5. Отключённый вид не предлагается при создании новой заявки.
6. Отключение не удаляет существующие заявки и не изменяет их историю.
7. Удаление видов отпусков через интерфейс не поддерживается.
8. Пользователь без роли администратора получает `403 Forbidden`.
