# ADR 0008: проверка типов на границе контроллеров

## Статус

Принято.

## Контекст

HTML-формы передают текстовые поля строками, но JSON-запросы могут передать
число или другой скаляр. До валидации модели такой ввод мог неявно стать
строкой или попасть в нормализацию, рассчитанную на строку. Структурированные
параметры года и месяца календаря молча заменялись текущими значениями.

## Решение

После `params.expect` проверять тип текстовых полей в контроллере. Если поле
передано, но не является строкой, возвращать HTTP 400 до изменения данных.
Для календарных фильтров применять ту же проверку до разбора года и месяца.
Некорректные скалярные значения месяца по-прежнему возвращают текущий месяц,
а ошибки содержания текстовых полей проверяются моделью и дают HTTP 422.

## Последствия

- JSON-запросы с числом вместо текста не создают и не изменяют записи.
- Структурированные календарные фильтры не маскируются значениями по умолчанию.
- Приложение не объявляет публичный JSON API; проверка защищает существующие
  контроллеры от неоднозначного ввода.
