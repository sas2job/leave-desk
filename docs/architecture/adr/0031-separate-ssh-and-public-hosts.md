# ADR 0031: разделение SSH-адреса и публичного имени выпуска

## Статус

Принято.

## Контекст

После перехода с HTTPS по IP на `leave-desk.duckdns.org` автоматический выпуск
успешно обновил сервер, но публичная проверка запросила IP из `DEPLOY_HOST`.
Сертификат для домена не содержит IP, поэтому проверка завершилась ошибкой
имени сертификата. `DEPLOY_HOST` также используется для SSH и связан с
настроенным `known_hosts`.

## Решение

Сохранить `DEPLOY_HOST` как адрес SSH. Перед публичной проверкой workflow читает
`LEAVE_DESK_PUBLIC_HOST` из серверного `.env`, проверяет форму имени и выполняет
HTTPS-запрос по нему. Внутренняя проверка приложения уже использует ту же
серверную переменную для заголовка `Host`.

## Последствия

Смена публичного адреса не требует замены SSH-секретов и `known_hosts`.
Публичная проверка сверяет сертификат с тем именем, которое обслуживает Caddy.
