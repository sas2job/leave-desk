# ADR 0046: документ пересечений из данных календаря

Отчёт получает те же строки сотрудников, фактические дни и дневные счётчики,
что и календарь. Поэтому число дней в документе совпадает с показателем календаря;
повторного независимого определения пересечения нет. Выводятся только месяцы
с пересечениями, соседние даты с одинаковыми участниками объединяются.

HTML и скачивание Markdown доступны только роли `manager` и непосредственным
подчинённым этого менеджера. Администратор сохраняет календарь отсутствий,
но отдельные показатели и документ пересечений ему не предоставляются.
Имена в Markdown экранируются; семейные основания в документ не входят.
