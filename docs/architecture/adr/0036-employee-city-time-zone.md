# ADR 0036: часовой пояс сотрудника по городу проживания

## Контекст

Администратор задаёт город проживания сотрудника. Для показа местного времени
нужно хранить его часовой пояс. Независимый ввод города и пояса допускает
несогласованные значения.

## Решение

Форма администратора предлагает фиксированный список городов. Модель
сопоставляет каждому городу идентификатор IANA и назначает пояс при сохранении.
Параметр `time_zone` из запроса администратора не принимается. Для ранее
созданных записей без города сохраняется пояс по умолчанию `Europe/Moscow`.
Development seed использует тот же список городов и не перезаписывает выбор
администратора при повторном запуске.

## Последствия

Новый город добавляется в общий справочник `User::CITY_TIME_ZONES`. Список
ограничен поддерживаемыми городами; расширение справочника требует изменения
приложения.
