# ADR 0050: общая ширина управления и расширенная диаграмма команды

Принято по запросу пользователя от 8 ноября 2026 года. Личный календарь
в месячном и годовом виде использует общую ширину страниц до 1080 px.
Заголовок, навигация, легенда и выбор пересечения командного календаря
выровнены по той же области; только диаграмма расширяется до 1540 px.
Это сохраняет привычное расположение управления и позволяет видеть больше
дней команды: месячная шкала с шагом 40 px и колонкой имён требует около
1420 px для 31 дня. Оба масштаба используют одинаковую компоновку.

На узких экранах боковые отступы совпадают с остальными страницами,
а шкала прокручивается внутри своей области. Переключение ширины отдельной
кнопкой не требуется. Решение дополняет ADR 0039, 0044 и 0049.
