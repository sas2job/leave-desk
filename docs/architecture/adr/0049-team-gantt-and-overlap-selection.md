# ADR 0049: Gantt для общего календаря и выбор участников пересечения

Принято по запросу пользователя от 7 ноября 2026 года. Развивает ADR 0038:
годовая матрица заменяется шкалой Gantt, месячная шкала сохраняется.

Оба масштаба используют один шаблон непрерывных полос с обрезкой по видимому
периоду, фактической дате окончания после отзыва/выхода и долями дня. Месяц
сохраняет шаг 40 px, год использует 3 px и заголовки месяцев с переходами
к подробному масштабу. Закреплённые имена и шапка сохраняют связь строк и дат.
Полоса открывает диалог с сотрудником и доступным описанием периода.

Чтобы поиск пересечений не требовал запоминания сотрудников при прокрутке,
менеджер выбирает совпадение из списка, дневного счётчика или HTML-отчёта.
Сервер принимает только дату и выводит участников соответствующего диапазона
из `TeamCalendarOverlapReport`, построенного по разрешённой команде.
Произвольные списки идентификаторов не используются. Счётчики выбранной шкалы
пересчитываются по показанным строкам; документ остаётся отчётом полной команды.

Семантика ADR 0046 сохраняется: совпадение календарных дат не утверждает точного
одновременного отсутствия. Частичные дни видны на полосах и в подробностях;
новый анализ точных интервалов и часовых поясов этим решением не вводится.
Отбор участников, показатели и документ доступны только менеджеру.
Администратор сохраняет обычную шкалу без анализа пересечений.

Периоды, события и основания заявок не изменяются. Кадровые основания и
семейный вид по-прежнему скрыты в общем календаре под «Длительное отсутствие».
