# ADR 0005: обязательный уникальный ключ подписи production

## Статус

Принято.

## Контекст

Шаблон серверного `.env` содержал непустую публичную заглушку для
`SECRET_KEY_BASE`. Docker Compose передавал её приложению без проверки.
Если использовать это значение на сервере, подписи cookie можно
воспроизвести, зная заглушку и идентификатор существующей сессии.

## Решение

Оставить значение `SECRET_KEY_BASE` пустым в шаблоне, требовать его заполнения
в Docker Compose и отклонять пустое значение и прежнюю заглушку при запуске
Rails в production. Для предварительной сборки ресурсов Docker использует
временный случайный ключ, не сохраняемый как runtime-переменная образа.
Production-ключ создаётся отдельно командой `bin/rails secret` и задаётся
только на сервере.

## Последствия

- Копия шаблона без настройки ключа не запустит приложение.
- При обнаружении прежней заглушки на сервере потребуется сменить ключ и
  прекратить доступ по ранее выданным cookie.
- Наличие безопасного ключа в фактическом production-окружении проверяется
  отдельно; код репозитория не раскрывает его значение.
