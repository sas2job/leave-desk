# ADR 0001: самостоятельная реализация на Rails

## Статус

Принято.

## Контекст

Leave Desk требуется поддерживаемая основа для процессов управления отпусками и разработки на основе спецификаций.

## Решение

Разрабатывать Leave Desk как самостоятельное приложение на Rails и PostgreSQL с собственной предметной моделью, интерфейсом и планом развития.

## Последствия

- Предметная модель может напрямую использовать соглашения Rails и ограничения
  PostgreSQL.
- Для каждой функции необходимы локальные критерии приёмки.
- Интеграции и миграции данных требуют отдельных спецификаций.
