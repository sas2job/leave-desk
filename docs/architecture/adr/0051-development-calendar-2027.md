# ADR 0051: воспроизводимый демонстрационный календарь 2027 года

Для проверки годового Gantt и отбора участников каждому демонстрационному
сотруднику добавляются два ежегодных отпуска и выходной в день рождения на
2027 год. Пересечения намеренно распределены по всем месяцам. Нерабочий день
рождения переносится на среду следующей календарной недели по производственному
календарю; заполненные даты рождения сохраняются.

Новые данные создаёт отдельный генератор development seed. Он моделирует
начало 2027 года средствами Active Support, чтобы пройти обычные проверки
даты и переходы `pending` → `approved` с историей и уведомлениями. Время
восстанавливается после запуска. Ограничение обычной формы текущим годом
для `BIRTHDAY` сохраняется; правило переноса не вводится глобально в модель.

Демонстрационные заявки узнаются по сотруднику, виду и отдельной метке
периода в комментарии. Повторный запуск сохраняет их даты, решения и события;
ежегодный отпуск выбирается среди свободных интервалов. Существующие данные
2026 года и справочные календари не заменяются. Требования зафиксированы
в спецификации 023.
