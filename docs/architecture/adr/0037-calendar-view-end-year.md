# ADR 0037: окончание календарного просмотра в 2050 году

## Статус

Принято.

## Контекст

ADR 0033 установил для личного и командного календарей диапазон просмотра
2025–2100. Пользователь сократил верхнюю границу до 2050 года.

## Решение

Оба календаря принимают годы 2025–2050 включительно. Запрос года за пределами
диапазона возвращает текущий год в пределах допустимого диапазона (после
2050 года — 2050 год). В декабре 2050 года и в годовом виде 2050
года ссылка на следующий период не показывается. Ограничение касается просмотра
календарей; допустимые даты заявок определяются отдельно.

## Последствия

Календарные страницы не открывают 2051 год и более поздние годы.
