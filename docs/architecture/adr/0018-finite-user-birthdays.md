# ADR 0018: конечные даты рождения сотрудников

## Статус

Принято.

## Контекст

PostgreSQL принимает `infinity` и `-infinity` в поле `date`; Rails возвращает
такие значения как `Float`. Проверка модели отклоняет их при обычной записи,
но не защищает прямые изменения БД. Уже сохранённое значение мешает открыть
календарь и форму редактирования сотрудника. Даты рождения до 2000 года
допустимы, поэтому диапазон дат заявок здесь неприменим.

## Решение

Ограничение БД запрещает неконечные даты рождения для новых и изменённых строк.
Миграция валидирует ограничение сразу, если таких строк ещё нет; иначе
оставляет его в состоянии `NOT VALID`, не удаляя данные и не блокируя выпуск.
Календари пропускают неконечные даты, а форма редактирования показывает пустое
поле, чтобы администратор мог исправить запись. После исправления всех старых
строк оператор валидирует ограничение командой PostgreSQL
`ALTER TABLE users VALIDATE CONSTRAINT users_finite_birthday`.
