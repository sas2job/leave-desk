# ADR 0014: отключить неиспользуемый Action Cable

## Статус

Принято.

## Контекст

Приложение не использует WebSocket-подключения. Открытый endpoint принимал
подключения без прикладной аутентификации. Production-адаптер Redis также не
обеспечен зависимостью и сервисом.

## Решение

Автоматическое монтирование `/cable` отключено настройкой
`config.action_cable.mount_path = nil`. Сейчас приложение не использует
WebSocket-подключения.

## Последствия

Если появится функция на Action Cable, для неё потребуется отдельное решение
об аутентификации подключений, адаптере и проверке обмена сообщениями перед
возвратом маршрута.
