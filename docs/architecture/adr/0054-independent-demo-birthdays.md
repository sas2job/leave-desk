# ADR 0054: независимые демонстрационные даты рождения

Пользователь отметил диагональное расположение дней рождения в алфавитном
списке команды. Прежняя формула выбирала месяц по индексу сотрудника.
Общий генератор демо-дат теперь использует отдельный фиксированный seed
и равномерный выбор дня невисокосного года; повторения дат допустимы.
Календарные год и месяц отпусков в этом выборе не участвуют.

Обычный seed заполняет только отсутствующую дату. Для существующих записей
стенда предусмотрена явно запускаемая коррекция исходной группы из 20
демо-учётных записей с сохранением года рождения и остальных полей профиля.
План проверяется по SHA-256, перед применением проверяется новая копия,
после применения выводятся фактические агрегаты. Существующие заявки и их
история сохраняются. Правила переноса выходного `BIRTHDAY` не изменяются.
