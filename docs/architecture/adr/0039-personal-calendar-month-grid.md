# ADR 0039: недельная сетка личного календаря

## Статус

Принято.

## Контекст

Личный месяц показывался одной длинной строкой из дневных ячеек. На широком
экране она оставляла большую часть страницы пустой, а на телефоне требовала
горизонтальной прокрутки для чтения собственных заявок.

## Решение

Личный месяц показывается неделями по семь дней. В каждом дне видны отдельные
заявки, их статус и вид отсутствия; подробные даты и точное время остаются в
доступном описании. Под сеткой расположен список заявок выбранного месяца с
датами и статусами. На телефоне дневные отметки сокращаются, а список даёт
полный текст. Годовой обзор остаётся горизонтальной матрицей.

Оба календаря используют компактную шапку, нейтральную основу и мягкие цвета
только для данных: видов отсутствия, статусов, дней рождения и совпадений.

## Последствия

Личный месяц читается без горизонтальной прокрутки. Для небольших экранов
сведения о заявке доступны в списке под календарём и в описании дня.
Права доступа и правила заявок не меняются.

Годовой вид позднее заменён компактной сеткой месяцев по ADR 0044.
