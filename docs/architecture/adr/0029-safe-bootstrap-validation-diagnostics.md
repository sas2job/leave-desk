# ADR 0029: безопасные ошибки первого администратора

## Статус

Принято.

## Контекст

Интерактивная команда создания первого администратора скрывала причину любой
ошибки валидации. Оператор не мог отличить пустое имя от неверного адреса или
короткого пароля. Прямой вывод ошибок модели мог бы непреднамеренно раскрыть
введённые данные в терминале или журнале.

## Решение

При `ActiveRecord::RecordInvalid` выводить только разрешённые названия полей
(`Name`, `Email`, `Password`) и фиксированные безопасные причины по типу ошибки.
Не вставлять значения полей, полный текст ошибки модели или её параметры.
Неизвестные ошибки получают общее сообщение. Ошибка по-прежнему завершает
команду с ненулевым кодом, а транзакция не сохраняет запись.

## Последствия

Оператор понимает, какое поле исправить, без раскрытия учётных данных.
Новые виды валидации требуют явной проверки прежде, чем добавлять подробный
текст диагностики.
