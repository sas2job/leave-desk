# ADR 0028: ограничение коллекций федерального календаря

## Статус

Принято.

## Контекст

Форма календаря могла принять тысячи повторяющихся строк. Даже после ошибки
уникальности валидация сверяла каждый перенос линейным поиском по праздникам,
создавая квадратичную нагрузку в пределах допустимого HTTP-запроса.

## Решение

Ограничить каждое поле формы 366 исходными строками до разбора дат, а каждый
JSON-массив — 366 элементами до нормализации. Это верхняя граница числа дней
любого поддерживаемого года. Проверка размера применяется и к прямой записи
модели. После ошибки исходного ввода или другой предпосылки зависимая проверка
переноса на праздник пропускается; при корректных предпосылках она использует
множество праздничных дат.

## Последствия

Разбор и сравнения дат имеют ограниченный объём. Избыточные пустые строки
формы тоже отклоняются; администратор может удалить их и повторить ввод.
