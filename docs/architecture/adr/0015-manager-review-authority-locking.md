# ADR 0015: блокировка сотрудника при рассмотрении заявки

## Статус

Принято.

## Контекст

Контроллер выбирает заявку среди заявок подчинённых руководителя. После этого
администратор может перевести сотрудника другому руководителю до фиксации
решения. Первоначальная проверка доступа тогда устаревает.

## Решение

Рассмотрение сохраняет блокировку строки заявки и до изменения статуса
блокирует строку сотрудника `FOR UPDATE`. Подчинённость читается из БД без
кэша и сравнивается с проверяющим. Изменение `manager_id` тоже требует
блокировки строки сотрудника при записи, поэтому решение и перевод получают
определённый порядок. При утрате полномочий контроллер возвращает `404`.

## Последствия

- Если перевод завершился первым, прежний руководитель не меняет заявку,
  историю и уведомления; новый руководитель может рассмотреть заявку.
- Если рассмотрение заблокировало сотрудника первым, перевод ждёт завершения
  решения. Принятое решение относится к руководителю на момент фиксации.
- Прямые SQL-изменения, обходящие обычную модель, не охвачены этим протоколом.
