# ADR 0055: проверенный стендовый календарь 2027 и точные метки дней рождения

Пользователь поручил наполнить и проверить 2027 год на стенде, исправить
широкую метку дня рождения и проверить большую команду. Ручная генерация
использует существующий генератор периодов с явным разрешением только
для демо-сотрудников стенда в 2027 году. Предварительная генерация откатывается;
применение связывается SHA-256 со снимком данных и планируемыми периодами.
Существующие справочники и история сохраняются.

Годовая метка дня рождения рисует точку 3 px, сохраняя доступную кнопку
24×24 px и диалог. Для кнопки выделена отдельная полоса строки, поэтому
область нажатия не перехватывает отпуск. Месячная плашка остаётся подробным
обозначением. Диалог различает день рождения и период отсутствия.

Стендовая проверка 100 сотрудников создаёт только транзакционный контрольный
набор и откатывает его после рендеринга настоящим контроллером. Она не требует
новых постоянных учётных записей. Браузерные регрессионные проверки выполняются
на искусственных данных CI; состояние и итоговые показатели стенда берутся
только с самого стенда.
