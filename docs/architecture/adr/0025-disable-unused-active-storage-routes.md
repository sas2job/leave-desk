# ADR 0025: отключение неиспользуемых маршрутов Active Storage

## Статус

Принято.

## Контекст

`rails/all` подключает Active Storage и по умолчанию публикует его маршруты.
Приложение не использует прикреплённые файлы и не содержит таблиц Active
Storage. Анонимная прямая загрузка доходила до отсутствующей таблицы и
завершалась ошибкой сервера. Загрузка JSON федерального календаря обрабатывается
обычной формой и не зависит от Active Storage.

## Решение

Отключить создание маршрутов Active Storage через
`config.active_storage.draw_routes = false`. Остальные компоненты Rails,
формы и выдача ассетов продолжают работать. Возврат загрузок потребует
отдельного решения о схеме хранения, доступе и проверке файлов.

## Последствия

- Неиспользуемые endpoints возвращают HTTP 404.
- Таблицы и production-зависимости не добавляются.
