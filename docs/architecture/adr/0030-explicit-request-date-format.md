# ADR 0030: явный формат дат в форме заявки

## Статус

Принято.

## Контекст

Нативное поле HTML `type="date"` показывает дату в формате, выбранном браузером.
На русскоязычной странице пользователь увидел порядок месяц/день/год. Атрибут
`lang="ru"` документа не гарантирует порядок отображения нативного поля.

## Решение

Форма заявки использует текстовое поле с форматом `ДД.ММ.ГГГГ` и точным
серверным разбором этого формата. Отдельное нативное поле служит только для
выбора даты: при поддержке `showPicker()` кнопка открывает календарь и
переносит выбранный день в текстовое поле. Без JavaScript дата вводится текстом.
API сохраняет приём дат ISO `ГГГГ-ММ-ДД`, а модель по-прежнему проверяет границы
и порядок дат.

## Последствия

Видимый формат не зависит от настроек браузера. Невозможная дата возвращает
ошибку формы с сохранением введённого текста. Календарь доступен в браузерах,
которые поддерживают `showPicker()`; в остальных работает текстовый ввод.
