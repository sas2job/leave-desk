# ADR 0042: проверка файлового ввода в служебных CLI

## Статус

Принято.

## Контекст

Импорт федерального календаря открывал переданный путь до проверки типа файла.
Именованный канал без писателя блокировал команду. Скрипт восстановления
принимал лишние позиционные аргументы и мог запустить `pg_restore`, молча их
проигнорировав.

## Решение

CLI импорта проверяет количество и форму аргументов до загрузки Rails, открывает
выбранный путь в неблокирующем режиме и проверяет тип открытого дескриптора.
Импорт допускает обычный файл, включая путь через символьную ссылку на него.
Ошибка аргументов, пути или содержимого JSON завершается кодом `2`; сбой
приложения или базы данных остаётся операционной ошибкой. Команда
восстановления требует ровно один аргумент и отклоняет лишние до проверки
архива и запуска `pg_restore`. Ошибки sidecar не выводят выбранный путь.

## Последствия

Канал FIFO и прочие специальные файлы не могут подвесить импорт. Сценарии
автоматизации отличают ошибку ввода от операционной ошибки по коду выхода.
