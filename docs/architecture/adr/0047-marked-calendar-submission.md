# ADR 0047: разметка календаря обязательна для отправки заявки

По требованию пользователя сотрудники не отправляют заявки на ещё не размеченные
годы. Публичный сценарий создания вызывает `submit`, проверяющий все годы периода
в тех же блокировках, что и сохранение. Требуются федеральная запись и полная
региональная запись при наличии региона сотрудника; ручные запросы не являются обходом.
Внутреннее сохранение исторических данных сохраняет прежний механизм неподтверждённого
расчёта, чтобы новое правило отправки не переписывало историю и не ломало импорт.
Календарь выбора и предварительный расчёт используют тот же перечень доступных годов.
