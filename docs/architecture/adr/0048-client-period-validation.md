# ADR 0048: проверка периода до отправки формы

Принято по запросу пользователя от 7 ноября 2026 года.

Планировщик связывает даты начала и окончания, выбранный вид и время крайних
дней. Ошибки существования даты, допустимого периода, разметки всех годов,
порядка дат и часов одного неполного дня устанавливаются через
`setCustomValidity`. Текст виден рядом с полем, связан через `aria-describedby`,
ошибочное поле получает `aria-invalid`. Исправление повторно вычисляет ошибки.

Браузер предотвращает отправку и фокусирует доступное ошибочное поле.
Для выходного в день рождения проверяется видимая единственная дата;
скрытое окончание не получает ошибку, требующую фокуса.
Отключение неполного дня очищает ошибки скрываемого времени.

Проверка браузера улучшает обратную связь, окончательные инварианты остаются
на сервере, включая работу без JavaScript и прямые запросы. Серверный снимок
разметки года может измениться после открытия формы; сервер проверяет его заново.

Устаревшее пояснение ADR 0040 о дробных ежегодных отпусках заменено правилами
спецификации 021: новые ежегодные отпуска оформляются полными днями.
