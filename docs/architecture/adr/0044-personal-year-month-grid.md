# ADR 0044: личный годовой обзор из двенадцати месяцев

Пользователь попросил видеть личный год на одном экране, а затем отдельно
рассмотреть командный обзор. Горизонтальная матрица из 365 столбцов требовала
прокрутки и запоминания дат. Вместо сжатия всех столбцов личный год показывается
двенадцатью календарными месяцами: четыре колонки на широком экране и меньше
на небольших. На 1366×900 весь обзор помещается по высоте; на телефоне
сохраняются читаемые даты и вертикальная прокрутка.

Годовой обзор показывает наличие согласованных и ожидающих заявок с буквенными
обозначениями, выходные, сегодня и день рождения. Описание дня сохраняет
вид и точное время всех заявок, включая совместные отметки. Ссылка месяца
открывает подробную недельную сетку. Это обзор собственных дат; он не заменяет инструмента
поиска пересечений сотрудников. Командный вид требует отдельного решения.
