# ADR 0045: кадровое основание отдельно от обычного согласования

Форма заявки показывает поля ребёнка только для `CHILDCARE`, а пояснения —
только для выбранного вида. Сервер задаёт исходные `hidden`/`disabled`,
JavaScript обновляет их при переключении; CSS сохраняет действие `hidden`
для полей с сеточной компоновкой. Скрытые поля не отправляются с формой.

Семейные отпуска оформляют право по заявлению и документам, поэтому их регистрирует
другой администратор; обычное управленческое отклонение заменено уточнением.
Неизменяемое кадровое основание хранится отдельно, а исходные даты заявки сохраняются.
Выход из ухода — инициатива работника с отдельной датой и состоянием `interrupted`;
новая связанная заявка сохраняет историю возобновления. Ограничение пересечений БД
и календари используют фактическую границу отсутствия.

Для ежегодного отпуска приложение проверяет полные дни и праздники, но не заменяет
кадровую проверку рабочего года и специальных прав искусственными лимитами 28/14.
Год и установленная продолжительность сохраняются в подтверждении. Новые записи
имеют снимок категории с ограничениями БД, старые периоды не переклассифицируются.

Корпоративный день рождения резервируется по сотруднику и календарному году.
Отмена после даты использования не освобождает право. Исторические дубликаты
сохраняются, вместо удаления выбирается носитель резервирования.

Граница совместимости схемы повышена до `20261106000002`: старое приложение
останавливается штатным workflow до миграций и не запускается на новых статусах.
